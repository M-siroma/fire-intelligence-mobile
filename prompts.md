# Registro de uso de IA

O edital permite o uso de IA para aprender e revisar, desde que os prompts sejam registrados e a equipe saiba explicar cada linha do código. Ferramenta usada: **Claude Code**.

Regras seguidas pela equipe:

- quem pediu o código leu, executou e testou antes de enviar ao repositório;
- nenhum dado, limiar ambiental ou endereço de API sugerido pela IA entra no projeto sem conferência na fonte oficial;
- cada etapa foi commitada separadamente, para o histórico mostrar a evolução.
